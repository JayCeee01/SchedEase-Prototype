More Information
  • Use one Excel sheet. Remove merged cells and replace formulas with their values.
  • Repeat shared details consistently. For example, use the same course name on its lecture and lab rows.
  • Lecture and lab minutes must add up to the course’s weekly hours.
  • Only enter qualifications the teacher holds. Original timetable columns are kept for reference.
  • Review links work for two hours. If a link expires, upload your file again.
